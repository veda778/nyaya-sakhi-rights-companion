# Nyaya Sakhi Rights Companion

Build out the complete frontend web application in Lovable and connect it to backend services for NYAYA SAKHI – AI-Based Legal Assistant for Women as specified in the attached document. Include the landing page, user dashboard, AI legal assistant with strict citations and refusal safety, Know Your Rights section, Government Schemes explorer with eligibility questionnaire, Complaint & Application drafter with PDF export, Emergency Helplines, multilingual support (English, Hindi, Kannada), and Admin management view, styled in deep purple and soft lavender.

This project was built with [Lovable](https://lovable.dev).

## Build with Lovable
